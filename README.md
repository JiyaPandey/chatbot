# **Simple NLP-Based Chatbot**  

## **Overview**  
This project is a **rule-based chatbot** built using **Python and NLTK**. It can respond to basic user queries and simulate a conversation. Designed for beginners in **Natural Language Processing (NLP)**, this chatbot uses predefined response patterns to interact with users.  

## **Features**  
✅ Greets users and responds to basic queries.  
✅ Recognizes common conversational phrases.  
✅ Provides simple assistance based on user input.  
✅ Rule-based responses using NLTK’s `Chat` module.  

## **Technologies Used**  
- **Programming Language:** Python  
- **Libraries:** NLTK  

## **Installation**  
### **1. Clone the Repository**  
```bash
git clone https://github.com/your-username/chatbot.git
cd chatbot
```
### **2. Install Dependencies**  
Ensure you have Python installed, then run:  
```bash
pip install nltk
```

## **Usage**  
Run the chatbot script:  
```bash
python index.py
```
Start chatting with the bot by typing your messages. To exit, type **"bye"**.  

## **Example Conversation**  
```
User: hi  
Bot: Hello! How can I assist you today?  

User: what is your name?  
Bot: I am a simple Python chatbot.  

User: I need help with Python  
Bot: Sure! How can I help you with Python?  

User: bye  
Bot: Goodbye! Have a great day!  
```
